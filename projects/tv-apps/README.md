# Television apps

Two related projects built for Samsung Tizen televisions:

- **[Vertex TV](vertex-tv.md):** an independent Jellyfin client with remote navigation, native playback, caching and explicit playback-conversion policy.
- **[Home launcher](home-launcher.md):** a personalised starting screen for installed apps, HDMI inputs, weather and settings.

The screenshots show actual interfaces captured from browser previews using fictional data. They are not photographs of a home or captures of a private media library.

The case studies distinguish user-tested behaviour from browser validation and remaining device checks. Source code, signed packages, certificates, deployment settings, logs, authentication data and unrelated personal records are outside this publication.
