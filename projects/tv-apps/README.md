# Television apps

Two related television projects, originally built for Samsung Tizen, with an LG webOS port:

- **[Vertex TV](vertex-tv.md):** an independent Jellyfin client with remote navigation, native playback, populated homepage shelves, in-player Up Next and explicit playback-conversion policy. See the [release history](CHANGELOG.md).
- **[Home launcher](home-launcher.md):** a personalised starting screen for installed apps, HDMI inputs, weather and settings.

The screenshots show actual interfaces captured from browser previews using fictional data. They are not photographs of a home or captures of a private media library.
